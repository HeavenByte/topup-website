## ✨ Deskripsi Proyek

**QuasarTopUp** adalah aplikasi web modern yang dirancang untuk memberikan pengalaman transaksi *top-up* *game* yang mulus dan memanjakan mata. Mengusung tema *Dark Mode*, *Glassmorphism*, serta tata surya (Nebula), proyek ini menetapkan standar baru untuk UI/UX pada *website top-up* di Indonesia.

## 🛠️ Teknologi yang Digunakan

- **Backend:** [Laravel](https://laravel.com/) (PHP)
- **Frontend:** [Tailwind CSS](https://tailwindcss.com/) & [Alpine.js](https://alpinejs.dev/)
- **Database:** MySQL
- **Assets/Build:** Vite
- **Animasi:** HTML5 Canvas API & CSS Keyframes
